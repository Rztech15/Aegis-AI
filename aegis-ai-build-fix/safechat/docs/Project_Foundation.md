# Project Foundation — AI Safe Communication Platform
*(Project Genesis — defined before any code is written)*

## Vision
A world where people can message freely without having to personally detect every scam, threat, or manipulation attempt themselves — because the platform quietly watches for danger and explains what it sees, while leaving every decision in the user's hands.

## Mission
To build the world's safest AI-powered communication platform that protects users from scams, harassment, phishing, and digital threats while respecting privacy and user control.

## Problem Statement
Existing messaging apps (WhatsApp, Telegram, Signal) deliver messages but provide no real-time safety guidance. Users face fraud, fake job/investment offers, harassment, threats, blackmail, and phishing links with no built-in support — safety is left entirely to individual judgment, often under pressure, with no explanation of *why* something feels wrong.

## Goals
- Detect fraud, scams, harassment, threats, and phishing patterns in real time
- Explain *why* a message is risky, not just flag it — a Risk Score plus a plain-language reason
- Let users save flagged conversations as evidence, with explicit permission
- Protect user privacy by design — minimum data storage, clear and revocable permissions
- Never make the decision for the user — AI warns and explains; the user (or relevant authority) decides

## Non-Goals (v1)
Explicitly *not* building yet — this keeps the team from scope creep:
- Group chats, voice/video calls
- Native mobile apps (web/prototype first)
- Full Signal-Protocol end-to-end encryption
- Multi-language support
- Business safety mode, family safety mode
- Automated blocking or reporting to authorities — the AI never acts unilaterally

## Target Users
*(To sharpen with real user research in Phase 1 — first draft:)*
- People who've previously experienced scams, harassment, or phishing over messaging apps
- Users in regions/communities with high exposure to messaging-based fraud
- Anyone messaging with strangers regularly — job seekers, online sellers, dating-app-to-DM users

## Core Principles
1. **Explain, never accuse.** The AI flags patterns and signals — it never labels a person a criminal or scammer.
2. **User control is final.** Every warning is a recommendation. The user always makes the last call.
3. **Privacy by design.** Minimum data collection, on-device analysis where possible, opt-in evidence storage only.
4. **Stability over speed.** No new feature starts until the current one is complete, tested, and stable.
5. **Trust is earned through accuracy.** False positives are treated as seriously as missed detections — both destroy user trust.
